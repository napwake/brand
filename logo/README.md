# The Napwake logo

One logo, always drawn the same. Use these files unchanged, under [TRADEMARKS.md](../TRADEMARKS.md). The full rules, with clear-space and construction drawings: [guidelines/logo.md](../guidelines/logo.md).

| File | Use it for |
|---|---|
| `lockup-horizontal.svg`, `-dark.svg` | The full logo, where there's width: headers, slides |
| `lockup-stacked.svg`, `-dark.svg` | The full logo in a square or narrow space |
| `symbol.svg`, `-dark.svg` | The mark alone, where the name is already shown or space is small |
| `wordmark.svg`, `-dark.svg` | The name alone |
| `symbol-on-coat.svg` | The mark in one colour on the brand's teal |
| `*-mono-ink.svg`, `*-mono-paper.svg` | One colour: ink on light, paper on dark |
| `avatar-500.png` / `.svg` (and `-dark`) | Profile pictures; survives a circle crop |
| `favicon-16*.svg`, `favicon-32.svg`, `favicon.svg` | Browser tabs; below 24 px use the 16-pixel cut, never a scaled-down symbol |

The plain files are for light backgrounds, `-dark` for dark ones.

**Clear space:** on every side, the height of the doorman's hat at that size, about a third of the symbol's height. Nothing else goes inside it.

**Smallest sizes:** horizontal lockup 100 px wide, stacked lockup 64 px wide, symbol 24 px.

**Don't:**
- stretch, squash, rotate or outline it, or add a shadow or a gradient;
- recolour it outside the palette; on a photo or a busy background, use a one-colour version;
- set "napwake" in a font in place of the drawn wordmark;
- use one of the doorman's poses, another expression or another hat as the logo;
- give him a mouth, a smile or a bow tie.
