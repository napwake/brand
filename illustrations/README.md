# The doorman

Napwake's doorman: his poses (`poses/`), the door glyphs (`doors/`: closed and dark is asleep, held ajar with amber light is waking up, open and lit green is awake, a pinned note is needs you), six UI icons (`icons/`), scenes (`scenes/`) and a sticker (`stickers/`). How to use each: [the guidelines](../guidelines/doorman.md).

Licensed [CC BY 4.0](LICENSE): use them anywhere, even commercially, and change them, as long as you give credit: "Doorman illustrations by Napwake, CC BY 4.0", linked to https://github.com/napwake/brand.

The doorman's head as used in the Napwake logo is part of the logo, in [`../logo/`](../logo/), and follows [TRADEMARKS.md](../TRADEMARKS.md) instead.
